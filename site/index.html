Core Capabilities

Built for fast, modular desktop computing

Appshell lets engineers ship and install native-feeling web applications that run in isolated desktop sandboxes with declarative permissions.

01

Sandboxed Runtimes

Each app has its own private filesystem partition and isolated local storage. Apps cannot read each other's data or access host filesystem unprompted.

02

Network Allowlisting

Apps declare the exact endpoints they communicate with. If no network permissions are requested, all external outbound network traffic is blocked.

03

Dashboard Widgets

Embed live micro-views, clocks, and notes directly into your system workspace dashboard without keeping full windows open.

System Architecture

Zero-overhead, verified source pipelines

The store is completely static and hands off directly to the desktop runtime via standard OS deep links (appshell://_/install/:id).

  • ✓ Pure Static Catalog: No tracking scripts, analytics cookies, or centralized account requirements.
  • ✓ Multi-channel Distribution: Support for stable releases and bleeding-edge beta channels.
  • ✓ Declarative Manifests: Standard JSON manifests specifying permissions, entrypoints, and widget hooks.

Integrity Guarantee

Cryptographic provenance on every install

Every release artifact is compiled directly from public source commits by automated GitHub Actions CI. The package is pinned by its exact SHA-256 digest in index.json.

Tamper-Proof Verification Protocol

Before unpacking or executing any downloaded app, the local Appshell client calculates the package checksum and halts installation if it differs from the catalog digest.
